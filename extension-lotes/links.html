IMPORTAÇÃO POR LINKS

Importar filmes de várias páginas

Cole uma URL por linha. Pode ser uma página com vários filmes (catálogo/listagem) ou a página de um único filme. A extensão encontra os filmes e importa seus players usando as funções já existentes.

Conectar ao ACERVO

Opcional para páginas individuais: Nome do filme | https://.... Nas páginas de catálogo, os títulos vêm dos cartões de filmes. URLs repetidas são ignoradas.

O navegador pedirá permissão para acessar os domínios escolhidos. Cada página é processada separadamente; filmes sem player compatível são registrados como falha. Mantenha esta janela aberta até o final.
